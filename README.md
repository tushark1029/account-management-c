# Account Management System 💳

## 📌 Overview

This project is a file-based banking system implemented in C. It allows users to securely create accounts, log in, and perform banking operations such as deposit, withdrawal, and fund transfer using text file storage.

---

## 🔐 Authentication

* Login using account number and password
* Password encryption using Caesar cipher + substitution cipher
* Credentials stored securely in `users.txt`
* Account locking mechanism after multiple failed login attempts

---

## 🏦 Features

* User signup with personal details
* View account balance
* Deposit money
* Withdraw money
* Transfer funds between accounts
* Transaction history tracking

---

## 💾 File Storage

* `users.txt` → stores account number, encrypted password, and user details
* `accounts.txt` → stores account number and balance
* `transactions.txt` → stores transfer records
